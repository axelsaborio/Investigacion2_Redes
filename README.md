# Investigación 2 - Redes Programables con P4

Proyecto del curso Redes de Comunicación de Datos.

## Descripción

Implementación de funcionalidades de redes programables utilizando
el lenguaje P4, el switch BMv2 y Mininet.

## Laboratorios

### Laboratorio 1 - Router IPv4 estático

Implementación de un router IPv4 programable con:

- Enrutamiento mediante Longest Prefix Match (LPM).
- Decremento del TTL.
- Reescritura de direcciones MAC.
- Descarte de paquetes sin ruta.
